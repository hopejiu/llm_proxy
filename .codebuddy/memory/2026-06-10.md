# 2026-06-10

## 完成内容

### 1. StatsPage 修复最近请求花费为 0 的 Bug
- **根因**: `computeModelCost` 期望 `total_input_tokens` / `total_output_tokens` / `total_cached_tokens`，但 `RequestLogVO` 返回的 JSON 字段是 `input_tokens` / `output_tokens` / `cached_tokens`（无 `total_` 前缀）。
- **修复**: 在 `enrichedRecent` 的 `.map()` 中将字段名映射后再传给 `computeModelCost`。

### 2. SessionsPage 增加搜索 + 后端分页 + 复用 RecentRequestsTable
- **后端**:
  - `internal/repository/chat_session_repo.go` 新增 `GetPaginated(page, pageSize, sessionID)` 方法，支持分页和按 session ID 精确搜索。
  - `stats_service.go` 新增 `GetSessionsPaginated(page, pageSize, sessionID uint) (PaginatedSessionsVO, error)`，返回 `{ sessions, total }`。
  - `vo.go` 新增 `PaginatedSessionsVO` 结构体。
  - 运行 `wails3 generate bindings -clean=true -ts` 重新生成绑定文件（534 Packages, 46 Methods）。
- **前端**:
  - `services/index.ts` 新增 `getSessionsPaginated` 方法。
  - `SessionsPage.tsx` 重写：输入框按 session ID 搜索（纯数字过滤）、分页控件（前后 + 省略号）、会话详情替换为 `<RecentRequestsTable showTps showCost>`（复用 StatsPage 的组件）。
  - 会话请求列表的 `_cost` 通过 `useProviders` + `buildPricingMap` + `computeModelCost` 前端计算，逻辑与 StatsPage 一致。

### 3. 统一自动刷新策略（删除开关，默认 2s）
- **StatsPage**: 删除 `useLocalStorage` 的 `autoRefresh` 开关和 UI 中的 toggle，改为默认 2s 轮询 `fetchAll`。保留手动刷新按钮。
- **SessionsPage**: 新增 `useRef` + 2s 自动刷新 effect（会话详情页中暂停轮询），header 添加手动刷新按钮。
- **RealtimePage**: 删除 `useLocalStorage` 的 `autoRefresh`/`interval` state，删除 toggle 和间隔选择器 UI。轮询改为永远 2s，但有流式请求 (`streamingCount > 0`) 时跳过刷新。

### 4. 修复 chat_sessions.total_cost 重复计费（缓存 token 被计费两次）
- **根因**: 后端 `calculateRequestCost` 输入费用 `inputTokens * InputPrice` 计算，未扣除缓存命中 token。前端 `computeModelCost` 正确使用 `(input - cached) * InputPrice`。
- **修复**: 后端改为 `paidInput = max(0, inputTokens - cachedTokens)`，与前端公式对齐。
